# AI Resume Screening - Frequently Asked Questions

## 1. How do I upload my resume?

To upload a resume, provide your resume file, job title, and required skills.

## 2. Which resume file formats are supported?

The supported resume formats are PDF, DOC, and DOCX.

## 3. What is the maximum resume file size?

The maximum allowed resume file size is 10 MB.

## 4. What information is required to upload a resume?

The required information is:

* Resume file
* Job title
* Required skills

## 5. What happens after I upload my resume?

The resume file is saved and a job record is created with the job title and required skills.

## 6. What information does the AI extract from my resume?

The AI extracts:

* Skills
* Total professional experience
* Highest qualification
* Certifications

## 7. Does the AI invent information that is not present in my resume?

No. The AI is instructed to extract information only from the resume and should not invent missing information.

## 8. What are matched skills?

Matched skills are skills identified in the resume that match the required skills for the job.

## 9. What are missing skills?

Missing skills are required job skills that are not identified in the resume.

## 10. What is the match score?

The match score represents how well the resume matches the job requirements.

## 11. What information is shown in the screening result?

The screening result can include:

* Match score
* Matched skills
* Missing skills
* Experience
* Qualification
* Certifications
* Screening result
* Recommendation
* Status
* Progress
* Current step

## 12. Can I view my screening result later?

Yes. A screening result can be retrieved using its screening ID.

## 13. What happens if the resume file is empty?

An empty resume file is rejected.

## 14. What happens if I upload an unsupported file format?

The upload is rejected if the file format is not PDF, DOC, or DOCX.

## 15. What happens if my resume is larger than 10 MB?

The upload is rejected because the maximum allowed file size is 10 MB.

## 16. Is job title required?

Yes. Job title is required when uploading a resume.

## 17. Are required skills needed?

Yes. Required skills are provided when creating the job associated with the resume screening.

## 18. What happens if screening result is not found?

The system returns a "Screening result not found" message when the requested screening result does not exist.

## 19. What happens if my resume has no certifications?

If no certifications are found in the resume, the AI returns an empty certifications list.

## 20. What happens if my experience cannot be determined?

If experience cannot be determined from the resume, the value can be returned as null.

## 21. What happens if my qualification cannot be determined?

If qualification cannot be determined from the resume, the value can be returned as null.

## 22. What is screening progress?

Screening progress indicates the current progress of the resume screening process.

## 23. What is the current screening step?

The current step indicates which stage of the screening process is currently being performed.

## 24. What is a recommendation?

The recommendation is the final recommendation generated by the screening system based on the screening result.
